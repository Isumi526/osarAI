# 実在識別子をプレースホルダー・例示・テストデータに使わない（INV-9）

正典: cc-pipeline `core/CLAUDE.md` INV-9（2026-08-04 追加）。

## ルール
- 実在の会社名・取引先名・チャネル名・**配布済みの紹介/プロモコード**・実顧客名・実メールアドレスを、以下に使わない:
  - コード例・コメント内の例示
  - UI の placeholder / デフォルト値
  - テストデータ・デモシード・E2E spec のフィクスチャ
  - ドキュメント・レビュー手順の文例
- **部分一致・接頭辞の流用も不可**。実在コードに社名略称が含まれる場合、その略称を含む `〜TEST` 系の派生名も禁止。
- 中立な値だけを使う: `TESTCODE01` / `example.com` / `テスト株式会社` / `サンプル太郎` 等。
- 実在値を使ってよいのは「本番でその値自体を検証する」場合のみ（そのときは例示ではなく実データとして扱い、扱いは INV-4/外部送信ルールに従う）。

## failure mode
- 例示のつもりの実コードが本番の有効コードと衝突・流用される。
- 社名・取引先名入りテキストがスクショ・ログ・外部LLM入力・共有ドキュメント経由で社外流出する。

## レビュー観点（diff に対して）
- 追加された placeholder / フィクスチャ / spec / シード / 文例に実在識別子（またはその派生）が含まれていないか。
- 含まれていたら severity=high で指摘（中立値への置換を提案）。
